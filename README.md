#«Поиск слов» (Word Search) — Осетинская версия


# 🎮 Филворды: Изучаем осетинский язык

Репозиторий содержит обучающую интерактивную игру-головоломку, разработанную на языке C# (Windows Forms).

---

## 1. Название проекта
**Обучающая интерактивная игра «Филворды: Изучаем осетинский язык»**

## 2. Короткое описание и правила игры
Приложение представляет собой лингвистический тренажер, предназначенный для легкого запоминания слов осетинского языка. 
* **Правила**: На квадратном поле из букв необходимо найти спрятанные слова по выбранной теме. Слова могут располагаться только по вертикали или горизонтали. 
* Игрок поочередно кликает на буквы слова (они подсвечиваются) и нажимает кнопку проверки. Задача — найти все слова за отведенное время.

## 3. Функциональные возможности
* **Гибкие настройки:** Регистрация имени игрока, выбор тем («Животные», «Люди») и уровней сложности (Легкий 5х5, Нормальный 7х7).
* **Умная генерация:** Автоматическое перемешивание банка слов и их случайное размещение на поле без пересечений.
* **Поддержка национального алфавита:** Использование специфической буквы осетинского языка **«Æ»** в словах и фоновом шуме.
* **Интерактивный UI:** Цветовая индикация состояний ячеек (желтый — выбор буквы, зеленый — слово угадано).
* **Игровой таймер:** Ограничение времени на раунд (90 или 180 секунд).
* **Система подсказок:** Возможность узнать случайное ненайденное слово со штрафом в общую статистику.
* **Сохранение рекордов:** Автоматическая запись результатов (имя, время, подсказки, тема) в локальный файл `records.json`.

## 4. Руководство администратора
* **Операционная система:** Windows 7 / 8 / 10 / 11.
* **Платформа:** .NET Framework 4.7.2 или выше.
* **Права доступа:** Программа должна иметь права на чтение и запись в своей рабочей директории. При первом запуске приложение автоматически создаст файл `records.json` в папке с исполняемым файлом `.exe`.

## 5. Руководство пользователя
1. Запустите приложение `NewGameFindWords.exe`.
2. В главном меню наберите имя и нажмите **«Играть»**.
3. В верхнем меню выберите тему («Животные» или «Люди»). Начнется отсчет времени.
4. Ищите слова, кликая левой кнопкой мыши по буквам на поле (они окрасятся в желтый).
5. Выделив слово целиком, нажмите **кнопку проверки**. При успехе буквы станут зелеными.
6. Если застряли, используйте пункт **«Подсказка»** в верхнем меню.
7. После нахождения всех слов ваш результат сохранится в историю.

## 6. Руководство программиста (Структура классов)
* `Program` — Главная точка входа, инициализирует графическую оболочку.
* `MenuForm` — Форма главного меню и навигации приложения.
* `NameInputForm` — Модальное окно для ввода и валидации имени пользователя.
* `GameForm` — Основное игровое окно (контроллер UI, таймера и JSON-сохранений).
* `RecordsForm` — Окно десериализации и отображения истории игроков из `records.json`.
* `GameBoard` — Логическое ядро (массив поля, алгоритмы `TryAutoAddWord` и генерация шума).
* `Word` — Класс-модель слова (текст, статус нахождения, массив координат).
* `Cell` — Класс-модель ячейки сетки (символ, координаты, флаги занятости).

Компьютерная игра для изучения языка, повторения знакомых и изучение новых слов.
2. Целевая аудитория.
Игра подойдет всем, кто хочет изучать язык или повторять знакомые слова; а также тем, кто просто любит игры, связанные с поиском слов. Возраст не важен: главное уметь пользоваться пк и иметь желание сыграть в данную игру.
3. Требования к программе или программному изделию а. Выделение букв для дальнейшей проверки. Буквы выделяем вертикально или горизонтально. Пока игрок выделил буквы, но ещё не проверил их-они выделяются оранжевым. После проверки, если слово правильное, то буквы становятся зелеными; в противном случае остаются серыми.
b. Выбор уровня сложности. В первом раунде изначально выбран
"Легкий уровень". Далее при желании игрок сам меняет уровень. с. Выбор категории слов
d. Подсчет оставшихся слов е. Просмотр результатов/правил/подсказок.
1. Окно "Подсказка" появляется при нажатии на кнопку
"Подсказка", если игрок не может понять какое слово не найдено на поле. В всплывающем окне появляется это слово.
Если не угаданных слов несколько, программа показывает 1 из них.
2. Окно "Правила". При нажатии на соответствующую кнопку появляется окно с правилами, на случай если игрок забыл их.
3. Окно "Результаты". При нажатии отображаются все результаты (Имя, количество угаданных слов за игру) пользователей, которые решили сохранить свой результат (для этого будет кнопка "Сохранить результат").
